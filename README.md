# VoyageOS · 通用多行程旅遊助手 (`gemini-travel-app`)

專為手機與電腦打造的**零建置通用旅遊 Web App（PWA）**，支援多段旅程自由切換、互動地圖與兩點車程測距、拖曳排行程、旅伴多幣別分帳、待辦打包、旅途照片日記，以及 **AI 純資料匯入新旅遊行程**。

- **線上網址（GitHub Pages）：** https://zlo-25.github.io/gemini-travel-app/
- **內建旅程資料：**
  1. 🌺 **`2027 4/2-4/10 沖繩情侶自駕`**（9天8夜完整自駕動線、JUNGLIA 叢林樂園＋森林溫泉、MapCode、住宿推薦與雙人預算分帳）
  2. 🇻🇳 **`2026 11/5-11/10 峴港`**（完整保留舊版 `Travel-app` 所有訂單、6 日行程、71 筆對齊帳務、訂製樂福鞋／藥妝圖鑑與筆記）

## ✨ 如何請 AI 幫你規劃並匯入下一個新旅遊行程？

本專案採用**「介面架構與行程資料完全分離」**設計。未來想去任何國家城市，**完全不需要改動任何 UI 或程式碼**！

只要對你的 AI 助手（Antigravity、Claude Code、Cursor、Codex 或 ChatGPT / Gemini）貼上這段話：

```text
請先閱讀 https://github.com/ZLO-25/gemini-travel-app 倉庫中的 AGENTS.md 與 PROMPTS/ADD_NEW_TRIP.md。
嚴格遵守「不改動任何 UI 與架構程式碼，僅新增 data/trips/<id>.json 並註冊至 data/manifest.json」的規範。
我接下來想去：【填入目的地與天數，例如：北海道 7天6夜】，請先問我缺少的必要資訊，確認後再幫我生成完整行程資料！
```

- **若 AI 有此 Repo 寫入權限**：AI 問完你的偏好後，會自動新增 `data/trips/trip_xxx.json`、更新 `data/manifest.json` 並執行 `python scripts/rebuild_seed.py` 推送上線，打開網頁就會自動出現新行程！
- **若使用純對話 AI（無 Repo 權限）**：請 AI 輸出單一 Trip JSON，打開 App 右上角 **「✨ AI 匯入」** 直接貼上 JSON，2 秒完成匯入！

## 🚀 核心功能亮點

1. **🗺️ 地圖與兩點距離車程深度結合**：
   - 支援 **「📅 行程動線模式」**（切換全行程或 Day 1～N 單日路線）與 **「📏 地圖兩點測距」**。
   - 在地圖上直接點選任意兩個景點圖釘（🟢 起點 → 🔴 終點），即時畫出路線並顯示公里數、高速公路 vs 一般道路車程、過路費、MapCode 複製與一鍵開啟 Google Maps 導航。
   - 無網路時自動降級為 **離線座標向量地圖**，飛機上也能看相對位置！
2. **🔍 全站秒搜 (`⌘K` / `Ctrl+K`)**：一秒搜尋跨模組的景點、MapCode、訂位代號、待辦、購物或花費。
3. **🗓️ 智慧行程時間軸**：自動計算並顯示相鄰兩站間的移動距離與車程膠囊，支援電腦與手機 `⠿` 跨日拖曳排序。
4. **💳 多幣別隨身換算 ＆ 旅伴自動分帳**：
   - 內建隨身外幣換台幣計算機；新增花費輸入原幣自動換算台幣。
   - 單人旅程維持清爽的「已付實際／未付預估／完旅總額」；雙人或多人旅程自動啟用 **旅伴墊付與結算建議**（誰給誰多少錢一鍵算好）。
5. **🔒 隱私密碼鎖 ＆ 離線 PWA**：
   - 沿用 SHA-256 瀏覽器端密碼鎖保護公開 GitHub Pages（同一分頁解鎖後保持登入，可隨時手動上鎖）。
   - 手機瀏覽器點選「加入主畫面」即可像原生 App 一樣全螢幕離線使用。

## 💻 本機預覽方式

零打包、零相依套件，直接啟動任一靜態伺服器即可：

```bash
python -m http.server 8080
```
接著開啟瀏覽器前往 `http://localhost:8080` 即可體驗完整功能。
